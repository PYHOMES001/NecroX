# NecroX

**Beyond Ordinary.**

NecroX is an immersive AI-powered 3D e-commerce platform for premium sneakers and streetwear.

## Foundation

- Next.js + React + TypeScript
- Tailwind CSS
- GSAP / Framer Motion
- Three.js / React Three Fiber
- PostgreSQL + Prisma
- Product variants with per-SKU inventory
- Cart, wishlist, orders, reviews and customer/admin roles

## Local setup

1. `npm install`
2. Copy `.env.example` to `.env`
3. Set `DATABASE_URL` to a PostgreSQL database
4. Run `npm run db:generate`
5. Run `npm run db:push`
6. Run `npm run dev`
